# SiteGo self-hosted fonts

Font binaries are installed locally with `scripts/install-self-hosted-fonts.ps1` on Windows or `scripts/install-self-hosted-fonts.sh` on Linux/macOS.

The project uses variable WOFF2 files from Fontsource 5.3.0:

- Instrument Sans, Latin + Latin Extended, weight axis 400-700
- Source Serif 4, Latin + Latin Extended, weight axis 400-600 in CSS

Both families are distributed under SIL Open Font License 1.1. The installer also downloads the upstream OFL license files into this directory.
